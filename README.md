# FPG Client — Interactive Residential Floor Plan Workspace

Web interface for defining residential planning requirements and visualizing floor plans generated by the FPG computational engine.

The client keeps the heavy optimization work on the backend and focuses on making the workflow understandable and interactive: define the land, configure rooms, request a layout, follow generation progress, and inspect the resulting 2D plan.

## Main Features

- Interactive **2D land-boundary editing**.
- Land scaling using a target site area.
- Road/access placement along the site boundary.
- Buildable-space calculation through the backend API.
- Room selection and floor-dimension configuration.
- Basic feasibility feedback before generation.
- Asynchronous generation-job submission.
- Real-time progress updates using **Server-Sent Events (SSE)**.
- Status polling for job recovery when required.
- 2D visualization of rooms, hallways, walls, labels, doors, and windows.
- Support for revising requirements and regenerating alternative layouts.

## Frontend Responsibilities

### Land & Site Setup

The canvas allows the site boundary to be adjusted visually and scaled to real-world dimensions. Road access can be placed on the relevant boundary before requesting the usable planning area from the backend.

### Room Configuration

Users can select room types, counts, and overall floor dimensions. Basic validation helps catch obviously incompatible requests before starting the more expensive generation process.

### Real-Time Job Monitoring

The backend performs multiple optimization and solving stages. The client keeps the interface responsive by working with asynchronous jobs and displaying live progress through SSE.

### Floor Plan Visualization

Completed room polygons, openings, walls, and labels returned by the backend are converted into drawing primitives and rendered as an interactive 2D floor plan.

## Running Locally

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

The client expects the FPG backend to be available for buildable-space calculations, room-constraint data, job management, and floor-plan generation.

## Project Scope

The interface is designed for **early-stage single-story residential layout exploration**. It provides the visual interaction layer for the generation system rather than performing the optimization itself.

## Related Repository

The companion server contains the FastAPI API, buildable-space logic, Optuna-based spatial search, OR-Tools CP-SAT solver, geometric refinement, opening generation, scoring, and asynchronous job-processing pipeline.
